# 项目规则（PR-x）

> 只写本项目特有、换项目不再成立的规则。通用红线在 ~/ai/rules.md，不在此重复。
> 编号用 **PR-01、PR-02**…（**不要用全局的红线编号前缀**，会撞号；全局规则见 ~/ai/rules.md）。
> 每条：**PR-x** 规则 ｜ 为什么 ｜ 怎么查

- **PR-01** 界面只使用现有 theme 色与图标体系；可以新增与现有风格一致的功能 SVG（如编辑笔），但不重画品牌图标、不混入其他图标风格。｜为什么：工作台要和 Herdr 其他面板看起来是一套。｜怎么查：新增样式只用 `theme()`，新图标沿用同一线宽、圆角和尺寸体系，diff 里不出现自造色板或重画品牌图标。
- **PR-02** 抓取、点击、忙碌、失败四类反馈必须一眼可辨，主操作直接可见、不做隐藏手势。｜为什么：用户要能判断操作有没有生效、下一步点哪里。｜怎么查：实拍按下/处理中/失败态，确认与常态有可感知差异，主入口无需悬停试探。
- **PR-03** 连续交互按真实过程验收：按住、跟随、让位、落位，不能用最终顺序正确或测试通过代替。｜为什么：顺序对了不代表手感对。｜怎么查：实机操作一次并留过程证据，不接受只看结果。
- **PR-04** 工作台尺寸与交互数字只在 [agent-workbench 设计契约](plans/agent-workbench.md) 维护，规则文档只链接不复述。｜为什么：避免两处数字不一致。｜怎么查：新增或修改工作台数字先进契约，其他文档只引用链接。
