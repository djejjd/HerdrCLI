# win98（主题外壳）

状态: active
创建: 2026-11-19
最后更新: 2026-11-19
关联: `layouts/win98.json`; `layouts/win98.svg`

定位：整套 Win98 主题外壳，不是侧栏方案。桌面、窗口、任务栏、助手形象都由宿主 `win98` mod
按 `role` 渲染，背景固定 `#008080`。属于主题试验，不作日常使用。

## 区域

| 区域 | 尺寸 | 内容 | 来源 mod |
|---|---|---|---|
| 桌面 | 撑满 | 桌面背景与图标层 | 宿主 `win98`（`role: desktop`） |
| 窗口 | 撑满 | 窗口边框与内容容器 | 宿主 `win98`（`role: window`） |
| 助手 | 浮层 | 助手形象 | 宿主 `win98`（`role: clippy`） |
| 任务栏 | 自适应 | 任务栏 | 宿主 `win98`（`role: taskbar`） |

窗口红绿灯内缩 `[14,14]`，终端内边距 `[4,2]`；没有侧栏、右侧面板与状态栏概念。

## 依赖

| mod | 来源 | 作用 |
|---|---|---|
| `win98` | 宿主内置 | 桌面、窗口、助手、任务栏 |
| `win98.svg` | 仓内 `layouts/` | 主题资源 |

仓库 `mods/` 里没有 `win98`，本布局完全依赖宿主；宿主缺该 mod 时不要启用。

## 外观

- `theme: win98`，`background: #008080`，`titlebar: none`。
- 视觉由 mod 与 `win98.svg` 共同决定，改色改图会同时影响四个 `role`。

## 启用与回退

```bash
herdr-app do layout.switch --name win98
herdr-app status
```

回退：切回 `main` 或 `agents-order`；本布局不写任何仓内 mod，回退不涉及清理。

## 适用与边界

- 适合：主题展示、录屏、演示。
- 不适合：日常开发（无侧栏与文件面板）、需要稳定阅读密度的场景。
- 当前仅为布局与静态资源，Windows 实机上的交互未单独验证；跨平台差异按宿主自身能力为准。
