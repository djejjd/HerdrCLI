# Agent 工作台与会话恢复

## 决策
沿用已确认样图：保留 Spaces，Agents 按 Space 分组，任务名优先。
同 Space 手动排序，状态变化不改变顺序；六点手柄启动拖动，Esc 或离开分组取消。
名称使用简短正式任务名，不读取对话正文；人工确认的任务名优先。
共享终端标签保存名称和排序，只有写入成功才完成同步。
14px 细线缺口圆环表示工作，需处理、完成、空闲使用不同形状。
窗格标题改为悬停覆盖层，避免重复占用终端高度。

## 会话状态转换
| 来源 | 事件 | 目标 |
|---|---|---|
| 活动 | Agent 进程结束或终端消失 | 最近会话 |
| 活动 | 只关闭 Herdr 窗口 | 活动 |
| 最近会话 | 手动恢复 | 恢复中 |
| 恢复中 | 精确会话身份和恢复成功证据 | 活动 |
| 恢复中 | 无身份、不支持、启动失败 | 恢复失败 |
| 恢复失败 | 手动新建 | 新建中 |
| 新建中 | 创建终端成功 | 已新建 |
| 新建中 | 创建失败 | 恢复失败 |

失败记录保留原因，不新增最近会话记录；新对话明确提示原上下文未恢复。
不得通过全局 latest 猜测原会话，不自动重新执行任务。
每个终态释放操作锁；失败只记录阶段和限额摘要，不保存终端或对话正文。

## 方案比较
改内置 mod 会被升级替换；直接改 core 成本高。
采用仓库管理个人 mod，通过安装脚本部署到 Herdr 配置目录。
先验证原生 API 能力，不能兑现的恢复能力明确提示原因。
